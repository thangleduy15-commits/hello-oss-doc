# Dự án Hello OSS

## Mô tả

Hello OSS là một chương trình C đơn giản dùng để thực hành quy trình phát triển phần mềm mã nguồn mở trên GitHub.

## Mục tiêu

* Làm quen với Git và GitHub.
* Biết cách tạo và quản lý repository.
* Biết cách viết tài liệu README.md.
* Biết cách viết tài liệu CONTRIBUTING.md.
* Làm quen với quy trình đóng góp cho dự án mã nguồn mở.

## Yêu cầu

Để chạy chương trình cần có:

* Trình biên dịch GCC.
* Git.
* Visual Studio Code.

## Cài đặt

Clone repository về máy:

```bash
git clone https://github.com/thangleduy15-commits/hello-oss-doc.git
```

Di chuyển vào thư mục dự án:

```bash
cd hello-oss-doc
```

## Biên dịch

Sử dụng GCC để biên dịch chương trình:

```bash
gcc -o hello main.c
```

## Chạy chương trình

Trên Windows:

```bash
.\hello.exe
```

Kết quả:

```text
Hello OSS
```

## Đóng góp

Nếu muốn đóng góp cho dự án, vui lòng đọc file `CONTRIBUTING.md` để biết cách báo lỗi và gửi Pull Request.

## Giấy phép

Dự án sử dụng giấy phép MIT.
